==================================================
PART A — WHAT CAMPUSPATH IS
==================================================

CampusPath AI is NOT:

- ChatGPT clone
- PDF chatbot
- simple quiz website
- normal LMS
- static dashboard
- generic RAG application

CampusPath is an AI-powered adaptive educational operating system.

Its main purpose is to build a continuously changing understanding of each student's knowledge.

For every student, CampusPath should determine:

- what they understand
- what they do not understand
- what misconceptions they have
- what prerequisite knowledge they may be missing
- how confident the system is
- what they should learn next
- what type of explanation works better for them
- what question difficulty is appropriate
- when they should revise a concept
- whether they have mastered a concept
- how prepared they are for upcoming assessments

For teachers, CampusPath should determine:

- which concepts the class understands
- which concepts are difficult
- which misconceptions are common
- which students are progressing well
- which students may require support
- what prerequisite gaps exist
- which CLOs are underperforming
- what remedial lesson may help

The project must combine several real AI techniques rather than putting everything inside one LLM prompt.

Core technologies/concepts:

PART C — IMPLEMENTATION PRINCIPLES
==================================================

Follow these rules throughout development.

1. Use Python as the main programming language.

2. Do not put the entire project into one Python file.

3. Use modular architecture.

4. Use deterministic Python algorithms where they make more sense than an LLM.

For example:

mastery calculation → Python
authorization → Python
graph traversal → Python
statistics → Python
scheduling → Python

Use LLM primarily for:

explanations
content understanding
question generation
answer interpretation
misconception interpretation
summarization
tutoring

5. Do not hard-code API credentials.

6. Do not leave buttons that do nothing.

7. If an external AI provider is unavailable, provide DEMO_MODE.

8. Every important AI output must be validated.

9. Do not trust generated structured data without validation.

10. Do not destroy working features while adding new ones.
